# exponent-2048

单文件、离线可玩的 2048 变体。方块用 2 的幂次表示，合并时按合成后的幂次加分。

打开 `exponent-2048.html` 即可开始，无需安装、无需联网。

## 方块表示

| 方块 | 主字符 | 十进制 |
| --- | --- | --- |
| 2⁰ | 留空 | 1 |
| 2¹ | A | 2 |
| 2² | B | 4 |
| 2³ | C | 8 |
| 2⁴ | D | 16 |
| … | … | … |

- 主字符：2⁰ 不显示，2¹ 起依次为 A、B、C…（对应 2 的指数）。
- 十进制数值显示在最近一次移动方向的一侧；左右移动时竖排显示。
- 字母与数值可以各自独立隐藏，也可以同时隐藏。

## 规则

- 方向键或 WASD 移动，相同幂次的两个方块相撞时合并为指数 +1 的方块。
- 每次合并按**合成后的幂次**加分（例如两个 A（2¹）合并为 B（2²），加 2 分）。
- 新方块生成概率：2⁰ 为 4/5，2¹ 为 4/25，2² 为 1/25。
- 无法继续移动时游戏结束。

## 视觉

- 六色循环：蓝、红、绿、橙、紫、黄；2⁰ 固定为浅灰。
- 不透明度从 25% 起，每提升一个幂次增加 5%，最高 100%。
- 深浅两套主题，可随时切换。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | 方向键 / WASD，或触屏滑动 |
| 暂停 / 继续 | 空格，或点击「用时」 |
| 撤销 | Ctrl+Z，或「撤销」按钮（全局撤销，可一直退回开局） |
| 新游戏 | 「新一局」按钮 |
| 显示设置 | 鼠标悬浮「显示」，选择隐藏字母 / 隐藏数值 / 隐藏加分 / 浅色 |

- 点击「用时」后，计时位置会短暂显示「已暂停」或「继续」。
- 显示设置菜单项文字表示**当前状态**（如已隐藏时显示「隐藏字母」）。
- 计时只累计分秒，满 60 分钟不进位为小时。

## 结束标语

游戏结束时按权重随机显示以下标语之一（合计 32）：

| 标语 | 权重 | 概率 |
| --- | --- | --- |
| 没有可移动方块了 | 8 | 1/4 |
| 完全卡住 | 4 | 1/8 |
| 过于拥挤 | 4 | 1/8 |
| GameOver | 15 | 15/32 |
| gAmeOver | 1 | 1/32 |
